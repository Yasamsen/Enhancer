# Yasam HD — Image Enhancer

Website HTML/CSS/JS murni, tanpa framework.

Fitur:
- Upload PNG/JPG/WebP
- Upscale 1x / 2x / 4x
- Ketajaman
- Detail / Clarity
- Kontras
- Auto Enhance
- Preview hasil
- Simpan PNG HD
- Semua proses berjalan di browser, tanpa upload ke server

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka `index.html` di Chrome/Edge/Firefox.
3. Pilih gambar.
4. Pilih 2x atau 4x.
5. Atur ketajaman/detail.
6. Tekan "Tingkatkan HD".
7. Tekan "Simpan HD".

Catatan:
Ini adalah enhancer berbasis Canvas, bukan AI super-resolution sungguhan. Untuk hasil yang benar-benar merekonstruksi detail yang hilang seperti AI upscaler, diperlukan model super-resolution (mis. Real-ESRGAN) yang dapat dijalankan di server atau WebGPU/WASM.
